# 图形规律大挑战 · 一年级进阶版

一个给一年级小朋友练习「找图形规律」的网页小游戏：**100 道题**，每题 4 个选项，答完自动讲解规律。

纯静态网页，无需安装依赖，可直接部署到 GitHub Pages。

## 玩法

1. 观察题目中图形的排列规律；
2. 从 4 个选项中选出「接下来」或「问号处」应该出现的图形；
3. 答对得 1 分，答错会高亮正确答案并显示规律说明；
4. 100 题结束后给出正确率、星级和错题回顾，可一键重练错题。

答题进度会自动保存在浏览器本地，中途关闭后再打开可以继续。

## 题目设计

100 道题共 10 类规律，每类 10 题，按轮次交替出现（每 10 题覆盖全部题型）：

| 题型 | 说明 |
| --- | --- |
| 三图形循环 | 3 个不同图形一组循环 |
| ABB 循环 | 1 个 + 2 个相同图形循环 |
| AABB 循环 | 2 个 + 2 个相同图形循环 |
| 形状 + 颜色双规律 | 形状 2 个一循环，颜色 3 个一循环 |
| 数量递增 | 每次多 1 个 |
| 数量递减 | 每次少 1 个 |
| 大小循环 | 小 → 中 → 大循环 |
| 箭头旋转 | 每次顺时针转 90° |
| 中间缺失 | 序列中间挖空，补出缺失图形 |
| 形状 + 大小双规律 | 形状 2 个一循环，大小 3 个一循环 |

题目由 `tools/gen-questions.mjs` 使用固定随机种子生成，结果可复现；生成时会做选项唯一性、答案唯一性和周期性歧义检查。

## 本地运行

```bash
# 任选一种静态服务器
python3 -m http.server 8787
# 然后打开 http://127.0.0.1:8787/
```

也可以直接用浏览器打开 `index.html`（本地文件方式下进度保存能力取决于浏览器）。

## 题库脚本

```bash
node tools/gen-questions.mjs     # 重新生成 questions.js
node tools/check-questions.mjs   # 题库自检：100 题 / 10 类 / 选项唯一
```

## 目录结构

```

├── questions.js        # 100 道题（自动生成）
├── tools/
│   ├── gen-questions.mjs
│   └── check-questions.mjs
├── package.json
└── LICENSE
```

## 部署到 GitHub Pages

1. 把仓库推送到 GitHub；
2. 打开仓库 **Settings → Pages**；
3. Source 选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`；
4. 保存后等待 1~2 分钟，即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。
